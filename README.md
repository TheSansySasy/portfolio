# sansysasy.com

Personal portfolio of **Sanskar Rai** (`@SansySasy`): Dynamics 365 F&O consultant, Python engineer, Azure and operations.

> Status: **Phase 0**, environment and scaffold. The full build plan lives in [PLAN.md](PLAN.md).

## Stack

Vite · React 19 · TypeScript (strict) · Tailwind CSS v4 · React Bits · GSAP · Motion · Lenis. Static output. A small FastAPI service in `api/` arrives in a later phase for the contact form and the live extraction demo.

## Develop

Requires Node 24 LTS and pnpm.

```bash
pnpm install
pnpm dev        # http://localhost:5173
pnpm build      # typecheck + production build to dist/
pnpm preview    # serve dist/ locally
pnpm lint
```
